# 三进制示例库与元件中文说明设计

## 目标

在快速演示版顶部工具栏加入“示例库”，用户可以查看示例用途并一键把完整
电路载入画布。右侧检查器在已有端口值和真值表之外，为全部 12 类基础元件
显示简短中文解释。

## 交互

- 工具栏“示例库”按钮打开模态窗口。
- 窗口列出示例名称、教学目标、主要元件和默认预期结果。
- 点击“载入示例”替换当前画布、关闭窗口并自动适应视图。
- 当前电路仍可移动、增删和连线。
- 按 `Escape`、关闭图标或点击遮罩关闭窗口。
- 载入操作不在 TypeScript 中计算门值，结果继续来自 Rust/WASM 快照。

## 首批示例

1. 三进制取反：`Input(0) -> NEG -> Probe`，默认输出 `0`。
2. MIN / MAX：输入 `T` 和 `1`，并行输出 `MIN=T`、`MAX=1`。
3. 三态译码：输入 `0`，`IS_ZERO=1`，另外两路为 `T`。
4. MUX3 选择器：数据端为 `T/0/1`，选择端为 `0`，默认输出 `0`。
5. 多驱动冲突：常量 `T` 和 `1` 同时驱动 Probe，默认网络值为 `E`。

## 文件边界

- `examples.ts` 只保存示例元数据和可深拷贝的编辑器文档。
- `component-help.ts` 只保存元件中文解释，不包含求值逻辑。
- `ExampleLibrary.tsx` 只负责示例库窗口。
- `App.tsx` 负责打开窗口、载入文档和把元件解释交给检查器。

## 验收

- 五个示例 ID、节点 ID 和连接 ID 均唯一，连接端点均存在。
- 五个示例均可通过 Rust/WASM 加载并得到预期 Probe 值。
- 12 类元件均有中文解释；门元件同时显示 Rust 目录真值表。
- 1440x900 下示例窗口和检查器不重叠、不产生横向溢出或控制台错误。
