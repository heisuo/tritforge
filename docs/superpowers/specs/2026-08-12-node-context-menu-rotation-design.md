# 元件右键菜单与旋转设计

## 目标

为画布上的全部元件提供右键菜单，并支持 `0/90/180/270` 四方向旋转。旋转必须同步改变元件几何、端口所在侧和连线锚点，导出后重新载入仍保持方向。

## 数据模型

`EditorComponent` 增加可选顶层字段 `rotation`，仅允许 `0 | 90 | 180 | 270`。缺省值为 `0`，旧工程无需迁移；序列化时保留非零和显式零值。该字段属于编辑器布局元数据，不进入 `properties`，也不传给 Rust 仿真组件，因此不改变逻辑语义或属性白名单。

## 交互

在元件上右键打开紧凑菜单，包含“顺时针旋转”“逆时针旋转”“删除”。菜单显示在鼠标附近并约束在浏览器可视范围内；点击菜单外、按 `Escape`、打开另一个菜单或执行命令后关闭。右键同时单选对应元件。

## 渲染

新增纯函数负责方向归一化、顺逆时针变换和逻辑端口侧到物理端口侧的映射。节点文字保持正向可读；`90/270` 时节点占位宽高交换，逻辑输入/输出分别映射到上/下或下/上。普通元件、模块边界、模块实例、存储器及 Wiring 元件共用相同方向模型。React Flow Handle 的 `Position` 必须使用旋转后的物理侧，使现有布线器自然获得正确进出方向。

## 验收

- 单元测试覆盖四方向循环、工程解析/序列化和端口侧映射。
- 浏览器测试覆盖右键打开、顺时针旋转、连线锚点改变、菜单关闭、刷新式重新载入保持方向和删除。
- 桌面 1440x900 截图确认菜单不溢出、文字可读、旋转节点与导线无明显重叠。
